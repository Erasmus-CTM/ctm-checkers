# ctm-checkers

The Python checker library of [CTM Assessment](https://github.com/Erasmus-CTM/ctm-assessment):
the grading code shared by math-exercise and stack-sympy, run in the browser
(Pyodide) and at build time. It is an internal library: course authors install
CTM Assessment, which includes it.

It holds math-exercise's checks, moved verbatim from math-exercise 0.10.0
(0.1.0), and stack-sympy's STACK engine, moved as it was at stack-sympy
`f450bcd` (0.2.0), in the October 2026 consolidation (step 2). The STACK
engine has a wheel and a page script of its own, so pages with math-exercise
never carry it. See
[ctm-assessment `docs/consolidation/`](https://github.com/Erasmus-CTM/ctm-assessment/tree/main/docs/consolidation).

- [docs/api.md](docs/api.md): the page script and `browser.call`, the
  request, the Python API, the checker namespace, build-time use, packaging.
- [docs/goldens.md](docs/goldens.md): the golden verdict tables.

## Layout

| Path | |
|---|---|
| `src/ctm_checkers/` | the package: `browser.py` (the page's entry), `math_exercise/`, `stack/` (STACK's engine), `core/`, `matrix.py`, `graph.py`, `testing.py` |
| `_extensions/ctm-checkers/` | generated by `tools/build.py` (do not edit): the two wheels, `ctm-checkers.js`, `ctm-checkers-stack.js`, `checkers.json`, `_extension.yml` |
| `examples/stack/` | the STACK question XML of CTM Assessment (its one home; stack-sympy's site copies it), with licences |
| `tests/` | tests (`pytest tests`; `tests/stack/` the STACK engine's, with its fixtures); `tests/golden/` the golden tables; `tests/pyodide/` the page scripts in Pyodide |
| `tools/` | `build.py`, `golden.py` and `golden_stack.py`, `pyodide/verify.cjs`, `stack_native/` (native STACK comparison, compliance report, corpus replay), `pins.json` (the commits CI uses) |
| `reports/stack-compliance/` | the Quarto project of the STACK compliance report (`.github/workflows/native-stack.yml`) |
| `docs/` | [api.md](docs/api.md), [goldens.md](docs/goldens.md), `stack/` (native STACK images) |

## Development

```sh
pip install -r ci/requirements.txt    # SymPy 1.13.3, mpmath 1.3.0, NetworkX, pytest
pytest tests
python tools/build.py                 # after changing src/: regenerate _extensions/ctm-checkers/
python tools/golden.py verify --adapter src --variants <math-exercise checkout>
PYTHONPATH=src python tools/stack_native/check_corpus.py --check   # STACK's corpus replay
```

`verify` records authored rows with the umbrella's recorder: check out
ctm-assessment at the commit in `tools/pins.json` into `_ci/ctm-assessment`
first (docs/goldens.md).

CI (`Tests`, `Pyodide`) checks the generated folder and the released
versions (`tools/released.json`), runs the tests on `src/` and on the built
wheels, verifies the golden tables with the built wheels and with
math-exercise 0.10.0's and stack-sympy `f450bcd`'s own code, and makes sure
that mutations of the checks fail them, on Python 3.9 to 3.13 and in Pyodide
0.27.2 and 0.28.3. A local `verify` works on any of those Python versions.
`Native STACK` compares the STACK engine with native STACK in Maxima and
renders the compliance report (stack-sympy's site calls it at its pin).
